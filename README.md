## How I work

- **Read first, then write.** I read the surrounding code before adding a line to it.
- **Small, reviewable commits.** Easy to bisect, easy to revert, easy to review.
- **Ship, then polish.** A working draft beats a perfect plan.
- **Name things properly.** Comments explain *why*, never *what*.
- **Consistency over cleverness.** The next person reading it is usually me.
